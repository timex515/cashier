# نقطة | نظام كاشير عربي

تطبيق نقطة بيع عربي بواجهة RTL مبني باستخدام Flask وSQLite.

## التشغيل على Windows

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000` في المتصفح. ينشئ التطبيق قاعدة `cashier.sqlite3` تلقائيًا ويضيف أصنافًا تجريبية عند أول تشغيل.

بيانات الدخول الافتراضية: اسم المستخدم `زيد` والرمز `1`.

## الاختبار

```powershell
python -m unittest discover -s tests -v
```

الخصائص: إضافة وتعديل وحذف الأصناف، البحث، متابعة المخزون، سلة بيع تفاعلية، طرق دفع متعددة، خصم تلقائي من المخزون، وسجل الفواتير.

## المستخدمون والصلاحيات

بعد تسجيل الدخول باسم `زيد` والرمز `1` افتح **إدارة المستخدمين** من القائمة. يمكنك إنشاء أي مستخدم جديد وتحديد الواجهات التي تظهر له. الواجهات والصلاحيات محفوظة في SQLite، وزيد يمتلك دائمًا كل الصلاحيات. عند تسجيل واجهة جديدة في `SCREEN_DEFINITIONS` ستُضاف تلقائيًا إلى جدول الواجهات وتظهر في خيارات الصلاحيات.
